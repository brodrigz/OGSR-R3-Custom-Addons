# Radiophobia Ledge Grabbing

Radiophobia adaptation for https://github.com/themrdemonized/Ledge-Grabbing-Mantling

Requires the Radiophobia OGSR 3.548 Engine Upgrade. Install the
engine upgrade first, then install this add-on and allow it to overwrite the
shared signal-module registry.

`gamedata` is the add-on payload source.  `third-party\demonized` retains the
upstream MIT license and provenance for the original Ledge-Grabbing-Mantling
project.

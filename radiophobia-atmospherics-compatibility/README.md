# Radiophobia Atmospherics Compatibility Patch

This is a compatibility overlay for **Atmospherics 2.69 RC6.5 OGSR Edition**
and Radiophobia 3 1.20 running the Radiophobia OGSR 3.529 Engine Upgrade. It is
not a standalone copy of Atmospherics.

Install Atmospherics normally then place the contents of this patch over it.

Existing saves worked during development testing, but back up saves before
changing the weather stack. Downgrading a save after writing it with a newer
engine/add-on combination is not guaranteed.
